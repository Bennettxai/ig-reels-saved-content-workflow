# Context profile

Every script this workflow writes has to sound like the user and only say true things about them. That comes from one file: `CONTEXT.md` in the repo root. Build it once, update it any time.

## Gather it

1. Ask the user for three to five of their own captions or video transcripts that performed well (paste them, or point to files). Read them for how they actually talk: sentence length, words they use, how they open, how they ask for the comment.
2. Ask these, one message, and wait for the answers:
   - What do you do, in one sentence a customer would understand?
   - Who is your viewer? (one real person, not "everyone")
   - What do you want them to do after watching? (comment a keyword, book a call, buy)
   - Three things that are true and you are happy to say on camera (results, numbers, stories). Nothing you would not swear to.
   - Words or styles you never want in a script.
   - Folders where your own footage lives (camera roll exports, B-roll, screen recordings).

## Write `CONTEXT.md`

Use the template already in the repo root and fill every section. Quote the user's own phrases where you can. Facts go under "True things I can say" exactly as given: the script skills may only use facts from that list, and leave a `[placeholder]` for anything else.

Show the user the finished file and ask them to correct anything that does not sound like them.
